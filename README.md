# Portfolio Website

A personal portfolio website for Goyal Kumar, built with plain HTML and CSS. A dark bento-grid layout with an intro card, tech stack, resources, learning notes and a "let's work together" section.

## Features

- Bento-grid portfolio layout
- About, tech stack and social links
- Mobile responsive layout — the grid collapses to one column on phone screens

## Tech

HTML · CSS

## Run it

Open `PorTFolio Website Desing/index.html` in any browser, or use a static server from the project folder:

```bash
npx serve "PorTFolio Website Desing"
```
